Pocket Forge – privacy policy

Applies to the Android app “Pocket Forge” (package com.k1lllagt.pocketforge). Last updated: November 12, 2026.

Summary

Pocket Forge does not collect, store on a server, share or sell any personal data. It has no accounts, no advertising, no analytics and no crash reporting. The app does not request the Android Internet permission, so it cannot send data over the network.

What the app does

Pocket Forge is a remote control for a build workspace that runs inside Termux, a separate terminal app that you install yourself. When you tap a button, Pocket Forge asks Termux, on the same device, to run a command, and then shows you the text that Termux returns. This happens entirely on your device.

Permission used

  • Run commands in Termux environment (com.termux.permission.RUN_COMMAND): lets Pocket Forge ask Termux to run commands. It is only used for the commands you start, and you can withdraw it at any time in Android settings.

Data kept on your device

  • Your chosen colour theme and a note that first-run setup is finished. These stay in the app’s private storage and are removed when you uninstall the app.
  • The command output shown on the Output tab is held in memory only.
  • If you tap Install workspace in Termux, the app hands its bundled installer script to Termux on the same device. Termux saves it in its own home folder and runs it in a window you can watch. You can read or delete that file at any time.

Other software

Termux and the tools the workspace runs (for example Gradle, the Android SDK, or rclone, if you choose to set up Google Drive sync) are separate programs with their own terms and privacy practices. Any network traffic they create is created by them, at your request, and is not seen by Pocket Forge or by its developer. Buttons that open F-Droid or GitHub open your web browser, which is governed by those sites’ policies.

Children

Pocket Forge is a developer tool and is not directed at children.
