Everything runs on the phone

create
Start from one of four templates: Compose, XML views, a WebView wrapper or a foreground service.
import
Copy in an existing Gradle project from a folder or a git URL. Your original is never changed.
auto
Pick a folder. It works out what is in it, builds it, and fixes common Gradle problems along the way.
build release

Wireless debugging, install, and colour-coded logcat.

Optional backup of your projects to your own Google Drive with rclone. Keys and secrets are excluded.

The app puts each of these behind a button, shows the output as it comes back, and has ten colour themes.

Questions

Do I need root?

No. It was built and tested on a phone that is not rooted.

Why does it need Termux?

Termux provides the Linux tools, Java, Gradle and the Android build tools. Pocket Forge drives them. That is why the app stays small and works without root.

What if a project will not build?

The Output tab shows the full log and has a Copy button, so you can search for the error or ask for help. The auto command can also show what it detected before it builds.

How do I install the APK?

Open the file. Android asks you to allow installs from the app you opened it with. Allow it for that app, then tap Install.

Is it affiliated with Termux or Google?

No. Termux is a separate open-source project. Android is a trademark of Google LLC.
